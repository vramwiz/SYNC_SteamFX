# 湯気演出（SYNC_SteamFX）

AviUtl ExEdit2 で料理、飲み物、温泉、白い息、蒸気機関車などの湯気を生成するメディアオブジェクトです。シーンサイズの透明画像を生成するため、料理や風景の素材に重ねて使えます。AviUtl ExEdit2 2.1.16 以降に対応します。

## 使い方

1. `SYNC_SteamFX.zip` を展開し、`SYNC_SteamFX` フォルダーを `C:\ProgramData\aviutl2\Plugin\` にコピーして、AviUtl2 を起動します。
2. メディアオブジェクトの「湯気演出」を追加します。初期値は「温かい料理」です。
3. 別の演出にするには「湯気プリセット」で選び、「設定」を押します。その後も各項目を調整できます。
4. 「発生源配置」の「発生位置X」「発生位置Y」で、湯気の発生位置を調整します。画像の中心が `(0, 0)` で、X の正方向は右、Y の正方向は下です。±8192 px の範囲で 1 px 単位の調整ができます。
5. 基底オブジェクトの「標準描画」で、画像全体の X・Y・Z、拡大率、透明度を調整します。プリセットを設定しても、発生位置と標準描画の値は保持されます。
6. 発生量を 0 にすると、すでに出ている湯気だけが寿命に沿って消えます。発生量をキーフレームで変化させると、発生の開始と停止を編集できます。

円形の発生源では円の内部全体と円周を選べます。噴射方向と風向は上が 0°、右が 90°です。噴射角度は正の値で奥を向きます。時間は秒単位です。「間欠放出型」では「連続」を選んだときに周期的放出、「瞬間放出型」では一回放出になります。瞬間放出は位相の時刻と、発生量を上げたタイミングに合わせられます。

## アンインストール

AviUtl2 を終了し、`C:\ProgramData\aviutl2\Plugin\SYNC_SteamFX\` フォルダーを削除します。
